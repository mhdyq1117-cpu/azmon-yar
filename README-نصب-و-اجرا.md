# راهنمای نصب و اجرای «آزمون‌ساز آنلاین پیشرفته» — نسخه ۲

این سند نحوه اجرای پروژه روی سیستم شخصی (ویندوز، مک یا لینوکس) را توضیح می‌دهد.

---

## ۱. پیش‌نیازها

| ابزار | نسخه پیشنهادی | توضیح |
|---|---|---|
| Node.js | ۲۰ یا بالاتر | از سایت nodejs.org نصب کنید (نسخه LTS) |
| npm | همراه Node نصب می‌شود | مدیریت پکیج‌ها |

فونت وزیرمتن به‌صورت لوکال داخل پروژه قرار دارد (`src/app/fonts`) و به اینترنت یا CDN وابسته نیست.

## ۲. نصب

```bash
# داخل پوشه پروژه
npm install
```

نکته: اسکریپت `postinstall` به‌طور خودکار کلاینت Prisma را تولید می‌کند. اگر به هر دلیلی تولید نشد، یک‌بار دستی اجرا کنید:

```bash
npx prisma generate
```

## ۳. دیتابیس

دیتابیس داخلی (SQLite) از قبل آماده و خالی است و **هیچ کار اضافه‌ای لازم نیست**.
اگر خواستید از صفر بسازید یا ریست کنید:

```bash
npm run db:push
```

فایل دیتابیس: `db/custom.db`

## ۴. اجرا (حالت توسعه)

```bash
npm run dev
```

سپس در مرورگر باز کنید: **http://localhost:3000**

## ۵. اجرا در حالت نهایی (Production)

```bash
npm run build
npm start
```

## ۶. اتصال به Supabase (ورود و ثبت‌نام معلم)

احراز هویت معلمان با Supabase Auth انجام می‌شود. فایل `.env` در ریشه پروژه از قبل تنظیم شده است:

```
NEXT_PUBLIC_SUPABASE_URL=https://anpsbkvmtjanpnfdiijq.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

- با همین مقادیر، حساب‌های ساخته‌شده قبلی (از جمله حساب فعلی شما) بدون هیچ تغییری کار می‌کنند.
- اگر خواستید پروژه Supabase دیگری وصل کنید، فقط این دو مقدار را در `.env` عوض کنید و برنامه را ری‌استارت کنید.
- داده‌های آزمون‌ها (سوالات، پاسخ‌ها، نمرات) در دیتابیس داخلی اپ ذخیره می‌شود و به هیچ اسکریپت SQL در پنل Supabase نیاز نیست. (فایل `supabase-setup.sql` فقط به‌عنوان پشتیبان برای حالت اختیاری نگه داشته شده است.)

## ۷. ساختار پروژه

```
azmoon-online/
├── src/
│   ├── app/                      صفحات (لندینگ، ورود، داشبورد، ویزارد، آزمون دانش‌آموز)
│   │   ├── page.tsx              صفحه اصلی
│   │   ├── auth/                 ورود و ثبت‌نام معلم
│   │   ├── dashboard/            داشبورد معلم + ویزارد ساخت آزمون + نتایج + تصحیح
│   │   ├── quiz/[id]/            ورود دانش‌آموز و صفحه آزمون
│   │   └── api/                  مسیرهای امن سرور (آزمون‌ها، پاسخ‌ها، نمره‌دهی)
│   ├── components/app/           کامپوننت‌های اختصاصی (تخته سفید، کپی لینک و ...)
│   ├── lib/                      توابع کمکی (اعداد/تاریخ فارسی، PDF، آمار، تصویر)
│   └── fonts/                    فونت وزیرمتن (لوکال)
├── prisma/schema.prisma          مدل‌های دیتابیس (Teacher, Quiz, Question, Submission)
├── db/custom.db                  دیتابیس SQLite آماده
├── screenshots/                  تصاویر صفحات اپلیکیشن
└── README-راهنمای-استفاده.md     راهنمای کاربرد و قابلیت‌های نسخه ۲
```

## ۸. نکات مهم

- رابط کاربری ۱۰۰٪ فارسی و راست‌چین است.
- گزینه صحیح سوالات تستی هرگز به مرورگر دانش‌آموز ارسال نمی‌شود؛ تصحیح در سرور انجام می‌گیرد.
- پس از ثبت نهایی، دانش‌آموز فقط پیام «پاسخ‌های شما با موفقیت ثبت شد. از شرکت در آزمون سپاسگزاریم.» را می‌بیند و هیچ نمره یا پاسخ درستی نمایش داده نمی‌شود.
- تصاویر بوم دست‌نویس و یادداشت‌های روی تصویر سوال به‌صورت فشرده داخل دیتابیس ذخیره می‌شوند.
- آزمون‌های زمان‌دار پس از پایان زمان، به‌طور خودکار قفل و ثبت می‌شوند و با رفرش صفحه زمان از سر گرفته نمی‌شود.
- کنترل بازه زمانی دسترسی (تاریخ شمسی) هم در مرورگر و هم در سرور انجام می‌شود.
